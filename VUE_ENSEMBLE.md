## 🎯 Cas d'usage typiques

### Cas 1 : Audit PME (50-100 users)
**Adapter :**
- Réduire durée dans `Planning_GANTT.csv` (3-4 semaines)
- Simplifier `Checklist_detaillee.csv` (focus essentials)
- Budget SOW : 25-30k€

### Cas 2 : Audit entreprise (200-500 users)
**Utiliser tel quel :**
- Package conçu pour ce périmètre
- 45k€ budget approprié
- 4-6 semaines durée standard

### Cas 3 : Audit multi-sites international
**Étendre :**
- Ajouter tâches GANTT par site/région
- Multiplier `Remediation_table` par zone
- Budget SOW : 80-120k€
- Durée : 8-12 semaines

## 🚀 Prochaines étapes

   ```bash

   cd audit-reseau-securite
   ```
